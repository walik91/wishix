# Поиск людей и отображаемое имя

Поиск доступен в `/my/search` авторизованному пользователю. Он ищет всех пользователей по части username или отображаемого имени, если владелец разрешил публикацию имени. Поиск регистронезависимый; `%` и `_` обрабатываются как обычные символы. Результат содержит только username и публичное имя и ведёт в публичный профиль. Личные и ссылочные списки поиском не раскрываются.

В профиле можно сохранить необязательное отображаемое имя и отдельно включить его публикацию. Флажок по умолчанию выключен. Приватное имя не участвует в поиске и не включается в публичные ответы. Публичное имя отображается и в публичном профиле. Пустое имя нельзя сделать публичным.

Рабочие параметры **предлагаются**: до 100 символов Unicode в имени и запросе, без управляющих символов; поиск по непустому запросу, до 20 человек на страницу, сортировка и курсор по username. Совпадение производится в CockroachDB через `lower` и `strpos`, с параметризованным запросом. Курсор не раскрывает закрытые данные. При изменении имени или публичности между страницами состав выдачи может измениться.

- `GET /api/search/people?q=...&after=...` — поиск для авторизованного пользователя; ответ `people` и `next_cursor`.
- `GET /api/profile/name` и `PUT /api/profile/name` — приватная настройка `{display_name, show_display_name}` для текущего аккаунта; мутация использует общие проверки Origin и JSON.
- `GET /api/public/profiles/{username}` возвращает только публичное имя.

Goose 011 добавляет поля без изменения существующих аккаунтов. Интеграционные тесты проверяют закрытость имени в поиске и профиле, поиск Unicode и username, переключение публичности, ограничение страницы и валидацию. Настройки аватара, возраста, описания и подписок не входят в этот этап.

Поиск подстроки сейчас выполняется без специализированного индекса; при росте числа аккаунтов потребуется измерить нагрузку и отдельно выбрать индексирование. Откат миграции 011 удаляет сохранённые имена и настройки их публичности и без отдельного согласования не выполняется.
