# Wishix — адаптивное демо

`index.html` — статический **визуальный пример** из дизайн-системы Wishix, не готовое приложение. Это тот же тип демонстрации, что в предыдущем комплекте: шапка, desktop sidebar, mobile bottom navigation, баннер, списки и желания.

Открыть `preview/index.html` в браузере. При наличии интернета подключается Inter через Google Fonts; иначе используется системный fallback. Можно также запустить сервер в корне распакованного архива:

```sh
python -m http.server 8000
```

Адрес: `http://localhost:8000/docs/design/preview/`.

Скриншоты сделаны на ширинах 320, 390, 768, 1024, 1440 CSS px. Имена, рубли, фотографии и позиции элементов служат примером. Кнопки без серверной логики — при интеграции следовать продуктовой спецификации.

## Страница приложения «Моё»

Этот раздел сохраняет снимки первого визуального этапа. Текущая реализация коллекции описана ниже.

`my-390.png` и `my-1440.png` — контрольные снимки реализованной Vue-страницы `/my` от 04.11.2026. Мобильный снимок показывает viewport 390×844, desktop — полную страницу при ширине 1440 px. Аккаунт `wishix_user` / `preview@example.com` подставлен только в изолированном проверочном браузере через перехват `/api/auth/me`; в приложении демонстрационного аккаунта нет, данные берутся из серверной сессии. Списки и желания оставлены визуальными шаблонами.

Проверены EN/RU/RO на ширинах 320, 390, 768, 1024 и 1440 px: отсутствие горизонтального overflow, touch-цели ≥44 px, переключение навигации и модальный фокус. Отдельно проверены loading/error/retry, длинные username/email, сохранение языка, reduced motion, ошибка/повтор выхода и переход на вход при отсутствии сессии. Снимки сверены с оригинальным макетом и брендбордом; mobile использует компактную CTA, desktop — иллюстрированный баннер.

## Рабочая коллекция и добавление желания

Последнее изменение формы: `wish-form-links-first-390.png` и `wish-form-links-first-1440.png` показывают ссылки первым блоком, до названия и изображения. Данные аккаунта подставлены только в проверочном браузере. Проверены EN/RU/RO на 320/390/768/1024/1440 px, клавиатурный порядок, добавление/удаление ссылок, ошибки и сохранение без URL. Парсер этим изменением не подключён.

Дополнение с загрузкой изображения: `wish-images-390.png`/`wish-images-1440.png` показывают карточку с реальным тестовым файлом, `wish-image-form-390.png`/`wish-image-form-1440.png` — предпросмотр выбранного файла. Аккаунт, желание и изображение созданы только в изолированной среде. Проверены JPEG/PNG/WebP, замена/удаление, ошибки/повтор, приватность и EN/RU/RO на пяти контрольных ширинах. Ниже сохранены снимки первоначального этапа без изображений.

`wishes-390.png`, `wishes-1440.png`, `new-wish-390.png`, `new-wish-1440.png` — снимки следующего этапа от 04.11.2026. `/my` показывает настоящие желания, `/my/wishes/new` — форму ручного добавления. Аккаунт и желания созданы только в изолированной тестовой среде `localhost:5174` с Mailpit. В рабочее приложение данные не подставлялись.

Проверены EN/RU/RO на 320/390/768/1024/1440 px, длинные тексты, focus/touch targets, загрузка, ошибки и повтор, добавление/удаление с сохранением в БД, подтверждение/отмена удаления, изоляция второго аккаунта и защита обеих приватных страниц. Набор прежних `my-*.png` оставлен как история визуального этапа.
