# Wishix — адаптивное демо

`index.html` — статический **визуальный пример** из дизайн-системы Wishix, не готовое приложение. Это тот же тип демонстрации, что в предыдущем комплекте: шапка, desktop sidebar, mobile bottom navigation, баннер, списки и желания.

Открыть `preview/index.html` в браузере. При наличии интернета подключается Inter через Google Fonts; иначе используется системный fallback. Можно также запустить сервер в корне распакованного архива:

```sh
python -m http.server 8000
```

Адрес: `http://localhost:8000/docs/design/preview/`.

Скриншоты сделаны на ширинах 320, 390, 768, 1024, 1440 CSS px. Имена, рубли, фотографии и позиции элементов служат примером. Кнопки без серверной логики — при интеграции следовать продуктовой спецификации.

## Страница приложения «Моё»

`my-390.png` и `my-1440.png` — контрольные снимки реализованной Vue-страницы `/my` от 04.11.2026. Мобильный снимок показывает viewport 390×844, desktop — полную страницу при ширине 1440 px. Аккаунт `wishix_user` / `preview@example.com` подставлен только в изолированном проверочном браузере через перехват `/api/auth/me`; в приложении демонстрационного аккаунта нет, данные берутся из серверной сессии. Списки и желания оставлены визуальными шаблонами.

Проверены EN/RU/RO на ширинах 320, 390, 768, 1024 и 1440 px: отсутствие горизонтального overflow, touch-цели ≥44 px, переключение навигации и модальный фокус. Отдельно проверены loading/error/retry, длинные username/email, сохранение языка, reduced motion, ошибка/повтор выхода и переход на вход при отсутствии сессии. Снимки сверены с оригинальным макетом и брендбордом; mobile использует компактную CTA, desktop — иллюстрированный баннер.
