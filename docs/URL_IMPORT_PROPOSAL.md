# Автозаполнение желания по ссылке

**Статус: реализовано по поручению владельца 2026-11-04.** Утверждено направление: один общий процесс для публичных сайтов и возможность узких адаптеров по подтверждённым проблемам. Имя файла сохранено для существующих ссылок. Численные ограничения ниже — предлагаемые рабочие параметры реализации.

## Поведение

- Первый валидный HTTP(S) URL запускает одну автоматическую попытку после паузы ввода 800 мс или выхода из поля. После неё повтор и импорт изменённой первой ссылки запускаются кнопкой. Дополнительные ссылки — только альтернативные места покупки.
- Заполняются название, одно изображение и пара примерная цена/валюта. Магазин, если указан в метаданных, показывается в сообщении. Исходная ссылка сохраняется как введена пользователем; редиректы не подменяют её.
- Форму можно заполнять и сохранять во время импорта. Изменённые вручную поля, включая явно очищенные, не перезаписываются. Цена/валюта заполняются только вместе, если ни одно из этих полей не изменялось вручную. Выбранная пользователем картинка имеет приоритет.
- Смена первой ссылки отменяет запрос и исключает поздний ответ. Прежние автоданные очищаются только в полях без последующих ручных правок. Сохранение и уход со страницы тоже отменяют запрос.
- Частичный результат заполняет найденное. Категории/списки товаров получают отдельное сообщение без логотипа и случайной цены из карточек. Ошибки не запрещают ручное сохранение с той же ссылкой.
- Автоданные нужно проверить. Нет фонового обновления цены, сравнения предложений или замены картинки у сохранённого желания.

## Общий процесс

`controllers.ProductImport → services.ProductImport → productimport.Importer`.

1. Безопасный GET исходного HTML без исполнения JavaScript, cookies и авторизации пользователя.
2. Инертный разбор через официальный `golang.org/x/net/html v0.62.0`. Основной источник — JSON-LD Product/Offer: корневые объекты, массивы, `@graph`, `mainEntity`, варианты ProductGroup. Внешний `@context` не загружается. Основной товар выбирается по URL, Offer URL, заголовку или единственному корневому Product; неоднозначные рекомендации не выбираются случайно.
3. Резерв — Product microdata/RDFa, Open Graph/Twitter, H1/title. Совпадающий H1 сохраняет вариант товара и убирает мусорный суффикс JSON-LD. Цена берётся только из предметных метаданных с явным трёхбуквенным кодом валюты. Символ `$`, рассрочка, аналитика и произвольные цифры текста не используются. Различающиеся цены Offer/AggregateOffer пропускаются. Десятичные строки обрабатываются без float и округления.
4. Изображения: Product → OG/Twitter → `image_src` и инертные JSON-атрибуты товара/галереи с полями image/photo/gallery. Это общий резерв без привязки к домену. Дубли исключаются; проверяются не более трёх URL. Ошибка картинки не отбрасывает текст.
5. `wishimage.Processor` проверяет реальное содержимое JPEG/PNG/WebP, размеры и EXIF-ориентацию, уменьшает и заново кодирует JPEG без исходных метаданных. Возвращается одна картинка до 512 КиБ.

Доменных исключений по умолчанию нет. Сайты, требующие JS, входа, CAPTCHA или блокирующие HTTP-клиентов, могут давать частичный результат или не импортироваться. Гарантии для всех страниц интернета нет. Подтверждённый сбой сначала воспроизводится, затем исправляется общий процесс или добавляется адаптер.

## API и хранение

`POST /api/wishes/import-preview`: приватная cookie-сессия, настроенный Origin, `X-Wishix-Request: 1`, JSON и проверка `Sec-Fetch-Site`. Тело до 4 КиБ, только `url` и `locale` (`en`/`ru`/`ro`; прочее → `en`); неизвестные поля и хвостовые значения отклоняются.

```json
{"url":"https://shop.example.com/product","locale":"ru"}
```

Ответ `200`: `status` (`ok`, `partial`, `empty`, `not_product`) и найденные `title`, `price` (точная десятичная строка), `currency`, `shop_name`, `image: {mime: "image/jpeg", data_base64: "..."}`. Отсутствующие поля пропущены. `Cache-Control: no-store`; HTML магазина, внутренние адреса и сетевые ошибки не возвращаются.

Ошибки: `401` — нет сессии; `403` — межсайтовый запрос; `400` — некорректный ввод/запрещённый URL; `415` — тип тела; `422 import_unavailable` — страница недоступна/непригодна; `429` — лимит/занятый обработчик; `503` — недоступность хранилища авторизации/лимитов.

Предпросмотр не создаёт желаний, изображений и черновиков в БД. Браузер превращает картинку в File и сохраняет обычным multipart POST `/api/wishes` после нажатия «Сохранить». Сервер повторно проверяет файл и атомарно сохраняет желание, ссылки и картинку. Закрытие формы не оставляет uploads. Счётчик запросов в БД используется отдельно от предметных данных.

## Безопасность — рабочие параметры

- Только публичные HTTP(S), стандартные порты 80/443, URL до 2048 байт, без userinfo, управляющих символов и служебных имён.
- При каждом соединении проверяются все DNS A/AAAA; смешанные публичные/внутренние ответы запрещены. TCP подключается к проверенному числовому IP без повторного DNS; TLS проверяет исходный hostname. Запрещены loopback/private/link-local/unspecified/multicast, metadata/CGNAT, специальные диапазоны, IPv4-mapped private и переходные IPv6-адреса.
- Каждый редирект и URL картинки проходит ту же политику. До трёх редиректов на ресурс. HTTP_PROXY/HTTPS_PROXY не используются.
- Общий срок — 15 секунд, ресурс — до 10 секунд, подключение/TLS — 4 секунды, заголовки — 6 секунд и до 32 КиБ.
- HTML до 2 МиБ после распаковки gzip, исходная картинка до 5 МиБ; лимиты применяются потоком. MIME и реальное содержимое изображения проверяются независимо.
- JSON-блок до 512 КиБ/32 уровней; обход HTML до 100 000 узлов/256 уровней. Нет eval, исполнения скриптов или скачивания embedded API.
- До двух импортов одновременно на процесс, до 20 попыток за 10 минут на аккаунт через атомарный счётчик CockroachDB. Ключ счётчика — HMAC. URL и содержимое магазина не логируются. Отмена клиента отменяет исходящий запрос.

## Адаптеры

Контракт `productimport.Adapter`: `Match(*url.URL) bool`, `Enrich(Document, Metadata) Metadata`. Document содержит финальный URL и инертное HTML-дерево, Metadata — результат общего извлечения. Первый совпавший адаптер дополняет/заменяет поля. Итог снова проходит нормализацию и общий безопасный загрузчик картинок. Реестр по умолчанию пуст.

При подтверждённой проблеме добавить точное сопоставление hostname/пути, HTML-фикстуру и тест изоляции от других доменов. Регистрация в Fx-провайдере `app.go`: `productimport.New(myAdapter{})`. Адаптер анализирует Document, не создаёт свой HTTP-клиент, не исполняет JS и не обходит общий загрузчик. Специфичный импорт может переопределить Metadata целиком.

## Проверки

- Go unit: извлечение JSON-LD/OG/microdata/RDFa/вариантов, точные цены, неоднозначность, категории, инертный JSON, изоляция адаптера, резерв картинки и JPEG. Сетевые тесты локальные: SSRF, смешанный DNS, закрепление IP, private redirect, лимиты gzip/ответа, типы и отмена.
- Интеграционные тесты на отдельной CockroachDB: сессия, Origin, строгий ввод, бюджет и отсутствие записей желания/картинки при предпросмотре.
- `front/tests/wish-import.browser.mjs`: поздний ответ, ручные правки/очистка/картинка, смена источника, альтернативные ссылки, повтор, сохранение при ошибке/категории/загрузке и EN/RU/RO × 320/390/768/1024/1440. API перехватывается; аккаунты не меняются. Требуются Playwright и Chrome; команда `node front/tests/wish-import.browser.mjs` против тестового Vite на 5174. `PLAYWRIGHT_MODULE` при необходимости задаёт путь к модулю, `WISHIX_TEST_ORIGIN` — локальный адрес.
- Живой Go-импорт 2026-11-04: Maximum, Darwin, Ultra, Crafti и отдельный товар Enter вернули название, цену/MDL и нормализованную картинку; категория Enter — `not_product`. Адаптеры не потребовались. Сквозная проверка с реальным API и тестовой почтой подтвердила импорт Crafti, отсутствие записи до сохранения, сохранение 49.95 MDL и картинки, восстановление после перезагрузки и запрет гостевого доступа.
