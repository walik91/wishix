# Несохранённые изменения настроек

**Приоритет:** P1

**Источник:** [UX-аудит настроек аккаунта](../resources/wishix_profile_ux_audit.md)

## Что изменить

Защитить несохранённые изменения при закрытии. Переключение вкладок уже сохраняет введённый текст, пока окно открыто.

## Промпт для ИИ

Найди диалог настроек аккаунта Wishix. Воспроизведение: открой «Профиль», введи текст в «О себе», закрой окно крестиком, открой снова. Добавь проверку несохранённых изменений для закрытия крестиком, Escape и клика по фону, если он закрывает окно. Предложи «Продолжить редактирование» и «Выйти без сохранения». Учитывай изменения имени, описания, даты, настроек видимости и введённого адреса, а также фото, если оно ждёт сохранения. Сравнивай значения с последним успешно сохранённым состоянием. При ошибке сохранения оставляй черновик. Проверь, что переход между вкладками сохраняет ввод, продолжение возвращает к форме, а после сохранения окно закрывается без предупреждения.
