Таск менеджер. В этой папке храним список задач и багов которые даются владельцем проекта в соотетствующих папках. ИИ сюда задачи и баги не пишет, за исключением если об этом попросил владелец проекта.
В папке bugs будут хранится баги и найденные ошибки. Каждый файл - отдельное описание ошибки.
В папке tasks будут хранится задачи. Каждый файл - отдельное описание задачи.
В папке done буду хранится завершенные задачи и баги. По сути владелец проекта будет удалять файлы после проверки задачи/бага.
В папке resources могут хранится изображения и другие файлы необходимые для задач и багов (сама задачча и баг будет ссылкать на какой либо файлы из ревурсов таск менеджера).

Когда дается команда выполнить задачи и баги из таскменеджера:
1. ИИ смотрит первый баг по списку
2. Если бага нет - берет первую задачу по списку
3. Если нет ни задачи - объявляет что нет задач и багов
4. Когда взял задачу или баг - выполняет ее согласно описанию
5. по завершении задачи/бага - возвращается к первому пункту

ИИ никогда не берет в работу несколько задач/багов одновременно. Только последовательно.
