# Собрать навигацию в одном месте

**Приоритет:** P1

**Источник:** [UX-аудит публичного профиля](../resources/wishix_public_profile_ux_audit.md)

## Промпт для ИИ

Найди публичный профиль `/u/:username` и страницы `/followers` и `/following`. Добавь общую компактную навигацию «Списки желаний», «Подписчики», «Подписки» с выделением текущей страницы и `aria-current="page"`. Сохрани существующие прямые адреса. На социальных страницах замени одиночный `@username` на явную ссылку «К профилю @username» со стрелкой. Формируй пункты из существующих правил видимости. Проверь переход между двумя открытыми разделами за одно действие, прямую загрузку, обновление и браузерное «Назад».
