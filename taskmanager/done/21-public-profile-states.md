# Развести пустоту, недоступность и загрузку

**Приоритет:** P2

**Источник:** [UX-аудит публичного профиля](../resources/wishix_public_profile_ux_audit.md)

## Промпт для ИИ

На страницах социальных списков сохрани компактные состояния «Подписчиков пока нет» и «Подписок пока нет» для открытого пустого раздела. Опирайся на существующие правила доступа и ответы при прямом переходе. Для закрытого или недоступного раздела используй сообщение, соответствующее действующей политике, либо существующий маршрут возврата. Для загрузки и ошибки используй общие компоненты проекта. Если количество уже доступно в разрешённых данных, покажи его в навигации и проверь согласованность. Критерии — пустой список понятен, закрытый раздел сохраняет действующий режим видимости, сбой загрузки не выглядит как ноль записей.
