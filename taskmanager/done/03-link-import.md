# Импорт по ссылке

**Приоритет:** P1

**Источник:** [UX-аудит Wishix](../wishix_ux_audit.md)

## Что показала проверка

У карточек AirPods Pro 3 на Darwin и Enter поля остались пустыми. Для Darwin ошибка появилась после ухода из поля ссылки, для Enter проверил явный запуск кнопкой импорта. Ссылка осталась в форме. Результат появился во временном уведомлении. Для ручного импорта видна кнопка с иконкой.

## Что изменить

Под полем пояснить «Даритель сможет открыть ссылку и увидеть нужный товар». Если импорт запускается автоматически, сообщить об этом в подсказке. Если доступен ручной запуск, подписать кнопку «Заполнить по ссылке». Результат показать временным уведомлением. При сбое подойдёт «Не удалось заполнить данные товара. Ссылка останется в форме. Введите название вручную». Проверить отказ на этих двух адресах и отдельно проверить успешный импорт.

## Промпт для ИИ

В форме поясни под ссылкой, что её увидит даритель и Wishix попробует заполнить данные по первой ссылке автоматически. Для ручного действия используй подпись «Заполнить по ссылке». Результат показывай существующим временным уведомлением. При сбое выведи «Не удалось заполнить данные товара. Ссылка останется в форме. Введите название вручную». Сохраняй URL вместе с желанием и сохраняй введённые вручную значения при позднем ответе импорта. Проверь успешный и частичный импорт, сбой, ручное сохранение со ссылкой и смену URL во время загрузки.
