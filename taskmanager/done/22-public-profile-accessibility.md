# Настроить фокус и мобильную локализацию

**Приоритет:** P3

**Источник:** [UX-аудит публичного профиля](../resources/wishix_public_profile_ux_audit.md)

## Промпт для ИИ

После перехода по общей навигации переводи фокус на заголовок целевой страницы или основной контент. При браузерном возврате из профиля человека по возможности восстанавливай фокус на открывавшей его строке. Проверь Tab, Shift+Tab, Enter и Escape для меню действий, видимость фокуса, переход к основному содержимому и чтение активного раздела. Проверь RU, RO и EN на ширине 340 и 390 CSS-пикселей, включая длинные имена и подписи.
